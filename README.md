# MR Vertrieb Lernsystem

Vertriebstrainings-App mit zwei Jobs, Kundenszenarien, gespeichertem Chat, Bewertung, Feedback, verbesserter Antwort, Verlauf, Erinnerungen und Admin-Bereich.

## Stack
- GitHub
- Supabase Auth + PostgreSQL + Row Level Security
- Statisches JavaScript-Frontend

## Backend
Supabase-Projekt: jligoehhclqpiyomiytd

Die Browser-App verwendet ausschließlich den öffentlichen Publishable Key. Service-Role-Secrets gehören nicht ins Frontend.

## Hinweis
Die aktuelle Bewertung ist eine kostenlose regelbasierte Erstversion. Eine echte KI-Bewertung kann später sicher über eine Supabase Edge Function ergänzt werden.
